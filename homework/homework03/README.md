# Homework 03 - Python Fundamentals

This submission explores `data/raw/starter_data.csv` with NumPy and pandas.
It includes vectorized and loop-based calculations, dataset inspection,
descriptive statistics, grouped aggregation, reusable code, and a basic plot.

The submission notebook is intentionally at the root of this homework folder,
beside `data/` and `src/`, as required by the course repository structure.

From this directory, run:

```bash
jupyter lab homework03_python-fundamentals_submission.ipynb
```

Restart the kernel and run all cells before submitting. The notebook reads the
provided input from `data/raw/`, imports reusable logic from `src/utils.py`, and
writes the reproducible tables and figure to `data/processed/`.
